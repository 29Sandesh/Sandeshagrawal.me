## 🚀 Overview

This repository houses my professional portfolio, built to showcase expertise in modern frontend engineering, programmatic SEO, and performance optimization. The project is designed with a "Performance-First" philosophy, achieving Lighthouse scores of up to **97** on production projects.

### Key Highlights:
- **Scalable Architecture:** Implemented a programmatic SEO system generating **1,100+ optimized city-specific landing pages**.
- **Performance Focused:** Optimized for sub-second load times using code-splitting, lazy loading, and asset compression.
- **Modern Stack:** Leverages **React 19**, **Vite**, and **Tailwind CSS 4** for a future-proof development workflow.

## 💻 Getting Started

### Prerequisites
- **Node.js** (v18 or higher)
- **npm** or **yarn**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/29Sandesh/MyPortfolio-main.git
   cd MyPortfolio-main
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Development Server:**
   ```bash
   npm run dev
   ```
   *The app will be available at `http://localhost:3000`*
